# Advanced Statistical Analysis & Hypothesis Testing

## Project Overview
This project demonstrates inferential statistical analysis using Python and the Wine Recognition dataset. It applies parametric and non-parametric hypothesis tests to identify statistically significant differences between groups.

## Objectives
- Perform normality testing using Shapiro–Wilk and Kolmogorov–Smirnov tests.
- Compare two independent groups using Welch's t-test and Mann–Whitney U test.
- Perform One-Way ANOVA and Tukey HSD post-hoc analysis.
- Perform Two-Way ANOVA to examine main effects and interactions.
- Calculate 95% confidence intervals.
- Visualize data distributions and summarize statistical findings.

## Dataset
The project uses the Wine Recognition dataset included in scikit-learn. It contains chemical measurements for three wine cultivars.

## Statistical Significance
The significance level used is alpha = 0.05. The notebook reports test statistics, p-values, confidence intervals, plots, and conclusions.
